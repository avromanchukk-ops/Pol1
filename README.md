# Полиця — трекер настільних ігор (Android)

Кожен пуш у `main` автоматично збирає APK (GitHub Actions) і публікує його у **Releases** як `Polytsia.apk`.

## Встановлення
1. Releases → остання збірка → `Polytsia.apk`.
2. Відкрийте файл на телефоні та дозвольте встановлення з невідомих джерел.

## Структура
- `web/src/*` — інтерфейс (HTML/CSS/JS). `python3 web/build.py` збирає `web/index.html` (шрифт Onest підтягується з npm).
- `android/` — нативна оболонка (WebView) + міст `Native` для запитів до BGG/RSS без CORS, вібрації, «Поділитися», збереження файлів.

## BoardGameGeek
З осені 2025 XML API BGG вимагає токен застосунку: зареєструйте застосунок на boardgamegeek.com/applications і вставте токен у «Ще → Налаштування та BGG». Без токена працює вбудований офлайн-каталог.
